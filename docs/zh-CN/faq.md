# Forumind 常见问题

[English](../faq.md) · **简体中文** · [繁體中文](../zh-TW/faq.md)

返回 [README](../../README.zh-CN.md) · 各项功能的详细说明见[使用指南](guide.md)。

### 所有 Discourse 论坛都能用吗？需要登录的论坛呢？
一般都能用，但论坛自己的设置仍然有效。Forumind 用你浏览器里的登录状态读论坛，所以你登录后能看到的内容，它也能读到，包括只有登录用户才能看的帖子。有些论坛会限制部分用户的搜索或阅读、限制读取速度，或者弹出自动请求过不去的人机验证，这时总结或回答可能不完整，或者失败。如果论坛要求你登录或通过验证，请在普通标签页里完成。全站搜索会暂停等待，完成后点 **继续**；总结的话，再点一次 **总结贴文** 就行。

### 提示需要验证，但我打开网站并没有看到验证？
这通常是 Cloudflare 把你的网络流量当成了机器人，用代理或 VPN 时很常见。可以在浏览器里直接打开 `https://论坛域名/t/1.json` 看看：如果这里也出现验证页面，就是网络环境的问题，换个节点或者先在这个页面通过验证再试。

### 为什么要逐个论坛授权？
Discourse 论坛分布在成千上万个不同的网站上，扩展没法提前知道。与其在安装时就要求"读取和更改你在所有网站上的数据"，不如在你第一次使用某个论坛时，只请求这一个论坛的权限。授权后，它可以用你的登录状态在后台读帖子和搜索（切换标签页后也能继续）。所有已授权的论坛都可以在 **设置 → 论坛访问** 里查看和移除，移除后保存的总结和回答不会被删除。

### 侧边栏显示"尚未检查此页面"。
Chrome 只允许 Forumind 查看你授权过的论坛，或者你点过它图标的页面。点工具栏上的 Forumind 图标，侧边栏就会检查这个页面。如果是 Discourse 论坛，会显示 **在 *论坛名* 上启用 Forumind**：点 **允许访问**，再在 Chrome 弹窗里选 **允许**。小技巧：在拼图图标菜单里固定 Forumind，图标就会一直在工具栏上。

### 从旧版本升级后，论坛又要我授权一次。
2.1 版把"访问所有网站"改成了"按论坛授权"，所以以前用过的论坛需要再点一次 **允许访问**。保存的总结和回答都还在。

### 我看到"rate limit"提示怎么办？
有两种情况。如果是*论坛*要求放慢速度，侧边栏会显示"论坛要求放慢速度"，稍等一会儿会自动重试，你什么都不用做。如果是你的 *AI 服务商*在限速，等一分钟再试，并检查你的套餐和用量。免费额度经常被限速的话，在侧边栏底部的输入框里一键切换到另一个模型就好（可以先在 **设置 → 常用模型** 里收藏几个）。

### "全站搜索"是灰色的，或者侧边栏认不出这个论坛。
在论坛页面打开时点工具栏上的 Forumind 图标，如果侧边栏提示，就点 **允许访问**（再在 Chrome 弹窗里选 **允许**）。也确认一下这确实是 Discourse 论坛（很多论坛页面底部写着 "Powered by Discourse"）。如果你在 **这是 Discourse 论坛吗？** 卡片上给一个其实不是 Discourse 的网站授权了，可以在 **设置 → 论坛访问** 里移除。

### 总结里写着"已达页数上限"或"前 1,999 条，共 2,430"。
你给 **每个话题阅读的页数** 设了上限，所以更长的话题只根据前几页总结。想包含更多，在设置里选 **阅读每一页**（或者提高上限），然后点 **检查新回复**。会花更长时间，也会多花一点钱。默认没有上限。极少数论坛不报告话题长度，这时为了安全，读到 100 页（10,000 帖）就会停。

### 怎么隐藏论坛页面上的 Forumind 按钮？
打开设置，滚动到 **论坛访问**，关掉 **在论坛页面上显示 Forumind 按钮**，然后点 **保存设置**。已打开的论坛标签页上的按钮会马上消失，工具栏图标仍然可以打开侧边栏。

### Ollama 报错"Ollama 拒绝了连接（403）"。
Forumind 会去掉它自己发往 `localhost`、`127.0.0.1` 和你允许的本地服务地址的请求里的 `Origin` 请求头，这样默认安装的 Ollama 就能接受。网页发的请求不受影响。如果仍然看到 403，请更新 Ollama 并重新加载扩展；实在不行，可以用 `OLLAMA_ORIGINS=chrome-extension://*` 启动 Ollama。

### 会发送哪些数据，发给谁？
只有完成你的请求所需的论坛内容和你的问题，发给你设置的 AI 服务商（或你的本地模型服务）。什么都不会发给我们。论坛会收到读取帖子和搜索的请求，这些请求从你的浏览器发出，带着你的登录状态，和你平时浏览时浏览器发的请求一样，所以论坛管理员可能在日志里看到它们。详见[隐私说明](guide.md#隐私说明)和[隐私政策](../../PRIVACY.md)（英文）。

### 为什么 Chrome 应用商店的版本比 GitHub 上的旧？
每个新版本都要先经过商店审核（Google 的，Edge 加载项则是微软的），耗时从几小时到几天不等，所以商店可能比 GitHub 慢一些。审核通过后浏览器会自动更新。想马上用新版，可以从 [Releases 页面](https://github.com/kccarlos/DiscourseCopilot/releases/latest) 安装 zip（见[使用指南](guide.md#从-github-安装最新版)），以后再换回商店版也可以。

### 收费吗？
扩展本身免费。你的 AI 服务商可能按用量收费，通常每次总结只要很少的钱。本地模型（Ollama、LM Studio）完全免费。

### 不小心删错了东西。
8 秒内点侧边栏底部提示里的 **撤销**（或者在不输入文字时按 Ctrl+Z，Mac 上是 ⌘Z）。超过 8 秒或者关掉侧边栏后，删除就无法恢复了。

### 怎么保留某个回答或对话？
点它上面的 **保留**。保留的内容永远不会过期。你也可以在设置里延长历史记录的保留时间。

### API key 好像有问题。
打开设置，检查 key 和模型，点 **测试连接**。也确认一下你的服务商账户里还有余额。
