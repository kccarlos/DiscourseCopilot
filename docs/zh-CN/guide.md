## 从 GitHub 安装最新版

每个新版本都要经过 Google 或微软审核，才能在 Chrome 应用商店或 Edge 加载项商店上架，耗时从几小时到几天不等，所以商店里的版本可能比最新的 [GitHub Release](https://github.com/kccarlos/DiscourseCopilot/releases/latest) 稍旧。想马上用最新版：

1. 打开 [Releases 页面](https://github.com/kccarlos/DiscourseCopilot/releases)，下载最新版本附带的 zip 文件。
2. 解压。
3. 在 Chrome 中打开 `chrome://extensions`（Edge 中是 `edge://extensions`），打开右上角的 **开发者模式**。
4. 点 **加载已解压的扩展程序**，选择解压后的文件夹。
5. 点工具栏上的拼图图标，固定 **Forumind**。

这样安装的扩展不会自动更新。要更新时，下载新的 zip，替换文件夹里的文件，再到 `chrome://extensions` 里点扩展卡片上的刷新图标。Chrome 启动时可能会提示"开发者模式"，这是正常的。之后也可以随时换回商店版，审核通过的新版本浏览器会自动更新。

## 侧边栏怎么用

- **总结贴文**：一键爬楼，读完整个话题（默认读完所有页，也可以设上限），写出主楼内容、大家的回应和关键结论。之后点 **检查新回复** 只会读新增的回复，不会把整栋楼再爬一遍。
- **所有提问都在底部的输入框里。** 选 **此帖子** 就针对当前话题提问：每一层楼都在上下文里，所以回答能告诉你是哪一层楼说的。选 **整个论坛** 则[搜索整个论坛](#使用全站搜索)。
- **在同一个输入框里切换模型。** 输入框会显示当前用的 AI 服务商和模型；在设置里收藏几个常用模型，就能在这里一键切换（免费额度被限速时特别好用）。
- **全部在后台运行。** 开始总结或提问之后，可以接着看别的帖子，回来再看结果，不用等 AI 吐完。
- **记录**（时钟图标）里有正在运行的任务，以及按论坛分组的已保存总结、对话和回答。点一行就能打开；点 **保留** 可以防止过期。

## 使用全站搜索

1. 在论坛页面点 **全站搜索**（或在输入框里选 **整个论坛**），输入你想知道的问题（比如"大家对 X 怎么看？"或者"这周有什么新消息？"）。
2. 侧边栏会实时显示 AI 的每一步：搜了什么关键词、读了哪些帖子、各有多少楼。展开某一步可以看到它为什么这么做、得到了什么结果。点 **停止** 可以随时停止。
3. 回答会附带 [S1] 这样的编号来源，点一下跳到对应的来源卡片，卡片链接到原帖。
4. 在回答下面可以**继续追问**，会在同一个论坛、同一段对话里继续，并重新获得一份搜索额度。

AI 用你的论坛登录状态去搜，所以只有登录用户（或达到一定信任等级的用户）才能看的帖子也能搜到。AI 只能读，不能写：它的工具只能搜索、列出和阅读帖子，以及查看你保存的总结，没有任何工具可以发帖或修改论坛内容。论坛内容作为引用材料交给模型，并要求模型不要执行其中的指令（写得很巧妙的文本仍然可能误导模型，这也是 AI 没有任何写入工具的原因）。因为 AI 每次只按固定格式执行一个动作，能力强一些的模型效果更好，很小的本地模型可能跟不上。

## 选择 AI 服务商

Forumind 不自带 AI。你可以连接一个已经在用的服务商，或者新注册一个。

| 服务商 | 需要什么 | 说明 |
| --- | --- | --- |
| OpenRouter | API key | 一个 key 就能用很多模型 |
| OpenAI | API key | GPT 系列模型 |
| Anthropic | API key | Claude 系列模型 |
| Google Gemini | API key（[Google AI Studio](https://aistudio.google.com/apikey) 可免费获取，有用量限制） | Gemini 系列模型 |
| Groq | API key | 速度很快的开源模型 |
| xAI | API key | Grok 系列模型 |
| DeepSeek | API key | DeepSeek 系列模型 |
| Ollama | 在电脑上安装 Ollama | 在本机运行，不需要 key，也不产生费用 |
| LM Studio | 在电脑上安装 LM Studio | 在本机运行，不需要 key，也不产生费用 |

**拿不定主意？** 已经在为其中某家付费，就用那家。想用一个 key 试很多模型，OpenRouter 是个简单的开始。Gemini 免费版有用量限制，Google 可能会用免费版的请求内容改进其产品。

粘贴 key 之后，模型栏会列出这个服务商当前提供的模型，并自动选一个适合做总结的、又快又便宜的模型。你随时可以换。

<summary>在电脑上使用 Ollama</summary>

启动 Ollama，然后在设置里选 **本地 (Ollama)**。不需要改任何 Ollama 设置：扩展会自动处理 Ollama 默认会拒绝的那个浏览器请求头（见[常见问题](faq.md#ollama-报错ollama-拒绝了连接403)）。地址默认填好 `http://localhost:11434`，LM Studio 默认是 `http://localhost:1234`。如果服务跑在另一台电脑上，填它的地址即可；点 **测试并保存** 时 Chrome 会请求一次连接权限。如果 LM Studio（或其他 OpenAI 兼容）服务器要求 API 密钥，请在 **设置 → AI 服务商 → API 密钥（可选）** 中填写。

## 自定义设置

在侧边栏里打开 **设置**，它会直接在侧边栏内显示，不用再关额外的标签页（在 `chrome://extensions` 里的扩展 **选项** 页面显示的是同一份设置）。大多数修改在点 **保存设置** 后生效（常用模型和论坛访问会立即生效），全站搜索、阅读话题、历史与隐私这几部分都有 **恢复默认值**。

- **AI 服务商。** 切换服务商、密钥或模型。模型列表来自你的服务商（点 **刷新模型列表** 重新加载）。已保存的模型不会被自动更换；如果服务商不再提供它，设置页会提醒你另选一个。
- **常用模型。** 收藏几个模型，就能在侧边栏的输入框里快速切换。
- **回答语言。** 默认是 **自动（与讨论语言一致）**：总结跟随讨论的语言，提问用你提问时的语言回答。也可以从 12 种语言里指定一种。
- **自定义指令。** 用你自己的指令代替内置的总结、对话和全站搜索指令。留空则使用默认指令。
- **全站搜索：研究深度。** AI 一步一步工作（一次搜索、一次阅读话题、一次列出最新话题），直到能够回答。**快速** 最多 6 步、读 3 个话题，**均衡**（默认）15 步、8 个话题，**深入** 25 步、14 个话题，**自定义** 可以自己设定步骤数、读取的话题数和每次读取的字符数。每次追问都会重新获得同样的额度。额度越大找到的越多，但耗时更长、花费更多。
- **阅读话题：每个话题阅读的页数。** 默认 **阅读每一页**，不管话题多长。想让超长话题更快、更省钱，可以选 **只阅读前** 若干页（1 到 100 页，每页 100 帖）。超过上限的话题只根据前几页总结，总结和对话里都会注明。
- **阅读话题：对话上下文。** 每次追问时随问题一起发送多少话题内容：默认 30,000 个字符（5,000 到 1,000,000）。也可以在侧边栏里调整。
- **历史与隐私：对话和全站搜索回答的保存时长。** 没有保留的对话和回答默认 **1 天** 后删除。可以选 3、7、30 天，或 **直到我删除**。点过 **保留** 的内容会一直保存。
- **历史与隐私：已保存话题数。** 默认最多记住 40 个话题的总结（10 到 200）。超过后，最早的未保留总结会被删除。
- **论坛访问。** 列出你允许过的每个论坛，可以 **移除访问权限**。已保存的总结和回答会保留。
- **论坛访问：在论坛页面上显示 Forumind 按钮。** 默认开启。关掉后论坛页面上的悬浮按钮会隐藏，保存后已打开的论坛标签页上也会立即消失，工具栏图标仍然可以打开侧边栏。
- **重置所有设置。** 在页面上确认后，清除所有服务商、密钥、模型、常用模型、自定义指令和偏好设置。已保存的总结和回答不会被删除。

界面提供英文、简体中文和繁体中文，跟随浏览器的语言自动切换。

## 隐私说明

- **密钥和历史记录都留在你的浏览器里。** 设置、API key、总结、对话和回答只保存在你的电脑上（扩展自己的存储里）。Chrome 以未加密的形式保存它们，所以能使用你这台电脑上 Chrome 个人资料的人都可能读到。可以在设置里删除，或者卸载扩展。
- **帖子内容只发给你选的 AI。** 你总结或提问时，话题内容和你的问题会直接从你的浏览器发给你的 AI 服务商。服务商怎么处理这些数据，请看它的隐私政策。用本机上的本地模型时，数据不会发到任何别的地方。
- **没有中间人。** 没有 Forumind 服务器，没有账号，也没有统计。
- **只读你启用的论坛。** 只有你在某个论坛点了 **允许访问**，Chrome 才会给扩展这个论坛的权限，你可以随时在设置里移除。你点工具栏图标时，扩展会对当前页面做一次检查，看它是不是 Discourse 论坛；对其他网站，它只知道这么多。侧边栏还会从你所在的论坛加载论坛图标（`/favicon.ico`）。

完整内容见[隐私政策](../../PRIVACY.md)（英文）。
