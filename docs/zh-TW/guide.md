## 從 GitHub 安裝最新版

每個新版本都要經過 Google 或微軟審核，才能在 Chrome 線上應用程式商店或 Edge 附加元件商店上架，耗時從幾小時到幾天不等，所以商店裡的版本可能比最新的 [GitHub Release](https://github.com/kccarlos/DiscourseCopilot/releases/latest) 稍舊。想馬上用最新版：

1. 開啟 [Releases 頁面](https://github.com/kccarlos/DiscourseCopilot/releases)，下載最新的 `forumind-<version>.zip`。
2. 解壓縮。
3. 在 Chrome 中開啟 `chrome://extensions`（Edge 中是 `edge://extensions`），開啟右上角的 **開發人員模式**。
4. 點 **載入未封裝專案**，選擇解壓縮後的資料夾。
5. 點工具列上的拼圖圖示，固定 **Forumind**。

這樣安裝的擴充功能不會自動更新。要更新時，下載新的 zip，替換資料夾裡的檔案，再到 `chrome://extensions` 裡點擴充功能卡片上的重新載入圖示。Chrome 啟動時可能會提示「開發人員模式」，這是正常的。之後也可以隨時換回商店版，審核透過的新版本瀏覽器會自動更新。

## 側邊欄怎麼用

- **產生摘要**：一鍵爬文，讀完整個話題（預設讀完所有頁，也可以設上限），寫出原始貼文內容、大家的回應和關鍵結論。之後點 **檢查新回覆** 只會讀新增的回覆，不會把整串討論再爬一遍。
- **所有提問都在底部的輸入框裡。** 選 **此貼文** 就針對當前話題提問：每一則回覆都在上下文裡，所以回答能告訴你是哪一樓說的。選 **整個論壇** 則[搜尋整個論壇](#使用全站搜尋)。
- **在同一個輸入框裡切換模型。** 輸入框會顯示當前用的 AI 供應商和模型；在設定裡收藏幾個常用模型，就能在這裡一鍵切換（免費額度被限速時特別好用）。
- **全部在背景執行。** 開始摘要或提問之後，可以接著看別的貼文，回來再看結果，不用等 AI 吐完。
- **紀錄**（時鐘圖示）裡有正在執行的任務，以及按論壇分組的已儲存摘要、對話和回答。點一行就能開啟；點 **保留** 可以防止過期。

## 使用全站搜尋

1. 在論壇頁面點 **全站搜尋**（或在輸入框裡選 **整個論壇**），輸入你想知道的問題（比如「大家對 X 怎麼看？」或者「這周有什麼新訊息？」）。
2. 側邊欄會即時顯示 AI 的每一步：搜了什麼關鍵詞、讀了哪些貼文、各有多少則回覆。展開某一步可以看到它為什麼這麼做、得到了什麼結果。點 **停止** 可以隨時停止。
3. 回答會附帶 [S1] 這樣的編號來源，點一下跳到對應的來源卡片，卡片連結到原始貼文。
4. 在回答下面可以**繼續追問**，會在同一個論壇、同一段對話裡繼續，並重新取得一份搜尋額度。

AI 用你的論壇登入狀態去搜，所以只有登入使用者（或達到一定信任等級的使用者）才能看的貼文也能搜到。AI 只能讀，不能寫：它的工具只能搜尋、列出和閱讀貼文，以及檢視你儲存的摘要，沒有任何工具可以發文或修改論壇內容。論壇內容作為引用材料交給模型，並要求模型不要執行其中的指令（寫得很巧妙的文字仍然可能誤導模型，這也是 AI 沒有任何寫入工具的原因）。因為 AI 每次只按固定格式執行一個動作，能力強一些的模型效果更好，很小的本機模型可能跟不上。

## 選擇 AI 供應商

Forumind 不自帶 AI。你可以連線一個已經在用的供應商，或者新註冊一個。

| 供應商 | 需要什麼 | 說明 |
| --- | --- | --- |
| OpenRouter | API 金鑰 | 一個 金鑰 就能用很多模型 |
| OpenAI | API 金鑰 | GPT 系列模型 |
| Anthropic | API 金鑰 | Claude 系列模型 |
| Google Gemini | API 金鑰（[Google AI Studio](https://aistudio.google.com/apikey) 可免費取得，有用量限制） | Gemini 系列模型 |
| Groq | API 金鑰 | 速度很快的開源模型 |
| xAI | API 金鑰 | Grok 系列模型 |
| DeepSeek | API 金鑰 | DeepSeek 系列模型 |
| Ollama | 在電腦上安裝 Ollama | 在本機執行，不需要 金鑰，也不產生費用 |
| LM Studio | 在電腦上安裝 LM Studio | 在本機執行，不需要 金鑰，也不產生費用 |

**拿不定主意？** 已經在為其中某家付費，就用那家。想用一個 金鑰 試很多模型，OpenRouter 是個簡單的開始。Gemini 免費版有用量限制，Google 可能會用免費版的請求內容改進其產品。

貼上 金鑰 之後，模型欄會列出這個供應商當前提供的模型，並自動選一個適合做摘要的、又快又便宜的模型。你隨時可以換。

## 自訂設定

在側邊欄裡開啟 **設定**，它會直接在側邊欄內顯示，不用再關額外的分頁（在 `chrome://extensions` 裡的擴充功能 **選項** 頁面顯示的是同一份設定）。大多數修改在點 **儲存設定** 後生效（常用模型和論壇存取會立即生效），全站搜尋、閱讀話題、歷史與隱私這幾部分都有 **還原預設值**。

- **AI 供應商。** 切換供應商、金鑰或模型。模型列表來自你的供應商（點 **重新整理模型列表** 重新載入）。已儲存的模型不會被自動更換；如果供應商不再提供它，設定頁會提醒你另選一個。
- **常用模型。** 收藏幾個模型，就能在側邊欄的輸入框裡快速切換。
- **回答語言。** 預設是 **自動（與討論語言一致）**：摘要跟隨討論的語言，提問用你提問時的語言回答。也可以從 12 種語言裡指定一種。
- **自訂指令。** 用你自己的指令代替內建的摘要、對話和全站搜尋指令。留空則使用預設指令。
- **全站搜尋：研究深度。** AI 一步一步工作（一次搜尋、一次閱讀話題、一次列出最新話題），直到能夠回答。**快速** 最多 6 步、讀 3 個話題，**均衡**（預設）15 步、8 個話題，**深入** 25 步、14 個話題，**自訂** 可以自己設定步驟數、讀取的話題數和每次讀取的字元數。每次追問都會重新取得同樣的額度。額度越大找到的越多，但耗時更長、花費更多。
- **閱讀話題：每個話題閱讀的頁數。** 預設 **閱讀每一頁**，不管話題多長。想讓超長話題更快、更省錢，可以選 **只閱讀前** 若干頁（1 到 100 頁，每頁 100 篇）。超過上限的話題只根據前幾頁摘要，摘要和對話裡都會註明。
- **閱讀話題：對話上下文。** 每次追問時隨問題一起傳送多少話題內容：預設 30,000 個字元（5,000 到 1,000,000）。也可以在側邊欄裡調整。
- **歷史與隱私：對話和全站搜尋回答的儲存時長。** 沒有保留的對話和回答預設 **1 天** 後刪除。可以選 3、7、30 天，或 **直到我刪除**。點過 **保留** 的內容會一直儲存。
- **歷史與隱私：已儲存話題數。** 預設最多記住 40 個話題的摘要（10 到 200）。超過後，最早的未保留摘要會被刪除。
- **論壇存取。** 列出你允許過的每個論壇，可以 **移除存取權限**。已儲存的摘要和回答會保留。
- **論壇存取：在論壇頁面上顯示 Forumind 按鈕。** 預設開啟。關掉後論壇頁面上的浮動按鈕會隱藏，儲存後已開啟的論壇分頁上也會立即消失，工具列圖示仍然可以開啟側邊欄。
- **重設所有設定。** 在頁面上確認後，清除所有供應商、金鑰、模型、常用模型、自訂指令和偏好設定。已儲存的摘要和回答不會被刪除。

## 隱私說明

- **金鑰和歷史紀錄都留在你的瀏覽器裡。** 設定、API 金鑰、摘要、對話和回答只儲存在你的電腦上（擴充功能自己的儲存裡）。Chrome 以未加密的形式儲存它們，所以能使用你這台電腦上 Chrome 個人資料的人都可能讀到。可以在設定裡刪除，或者解除安裝擴充功能。
- **貼文內容只發給你選的 AI。** 你摘要或提問時，話題內容和你的問題會直接從你的瀏覽器發給你的 AI 供應商。供應商怎麼處理這些資料，請看它的隱私權政策。用本機上的本機模型時，資料不會發到任何別的地方。
- **沒有中間人。** 沒有 Forumind 伺服器，沒有帳號，也沒有分析。
- **只讀你啟用的論壇。** 只有你在某個論壇點了 **允許存取**，Chrome 才會給擴充功能這個論壇的權限，你可以隨時在設定裡移除。你點工具列圖示時，擴充功能會對當前頁面做一次檢查，看它是不是 Discourse 論壇；對其他網站，它只知道這麼多。側邊欄還會從你所在的論壇載入論壇圖示（`/favicon.ico`）。

完整內容見[隱私權政策](../../PRIVACY.md)（英文）。
