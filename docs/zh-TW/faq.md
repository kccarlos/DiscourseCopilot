# Forumind 常見問題

[English](../faq.md) · [简体中文](../zh-CN/faq.md) · **繁體中文**

返回 [README](../../README.zh-TW.md) · 各項功能的詳細說明見[使用指南](guide.md)。

### 所有 Discourse 論壇都能用嗎？需要登入的論壇呢？
一般都能用，但論壇自己的設定仍然有效。Forumind 用你瀏覽器裡的登入狀態讀論壇，所以你登入後能看到的內容，它也能讀到，包括只有登入使用者才能看的貼文。有些論壇會限制部分使用者的搜尋或閱讀、限制讀取速度，或者彈出自動請求過不去的機器人驗證，這時摘要或回答可能不完整，或者失敗。如果論壇要求你登入或透過驗證，請在普通分頁裡完成。全站搜尋會暫停等待，完成後點 **繼續**；摘要的話，再點一次 **產生摘要** 就行。

### 提示需要驗證，但我開啟網站並沒有看到驗證？
這通常是 Cloudflare 把你的網路流量當成了機器人，用代理或 VPN 時很常見。可以在瀏覽器裡直接開啟 `https://論壇網域/t/1.json` 看看：如果這裡也出現驗證頁面，就是網路環境的問題，換個節點或者先在這個頁面透過驗證再試。

### 為什麼要逐個論壇授權？
Discourse 論壇分佈在成千上萬個不同的網站上，擴充功能沒法提前知道。與其在安裝時就要求「讀取和更改你在所有網站上的資料」，不如在你第一次使用某個論壇時，只請求這一個論壇的權限。授權後，它可以用你的登入狀態在背景讀貼文和搜尋（切換分頁後也能繼續）。所有已授權的論壇都可以在 **設定 → 論壇存取** 裡檢視和移除，移除後儲存的摘要和回答不會被刪除。

### 側邊欄顯示「尚未檢查此頁面」。
Chrome 只允許 Forumind 檢視你授權過的論壇，或者你點過它圖示的頁面。點工具列上的 Forumind 圖示，側邊欄就會檢查這個頁面。如果是 Discourse 論壇，會顯示 **在 *論壇名* 上啟用 Forumind**：點 **允許存取**，再在 Chrome 彈出視窗裡選 **允許**。小技巧：在拼圖圖示選單裡固定 Forumind，圖示就會一直在工具列上。

### 從舊版本升級後，論壇又要我授權一次。
2.1 版把「存取所有網站」改成了「按論壇授權」，所以以前用過的論壇需要再點一次 **允許存取**。儲存的摘要和回答都還在。

### 我看到「rate limit」提示怎麼辦？
有兩種情況。如果是*論壇*要求放慢速度，側邊欄會顯示「論壇要求放慢速度」，稍等一會兒會自動重試，你什麼都不用做。如果是你的 *AI 供應商*在限速，等一分鐘再試，並檢查你的方案和用量。免費額度經常被限速的話，在側邊欄底部的輸入框裡一鍵切換到另一個模型就好（可以先在 **設定 → 常用模型** 裡收藏幾個）。

### 「全站搜尋」是灰色的，或者側邊欄認不出這個論壇。
在論壇頁面開啟時點工具列上的 Forumind 圖示，如果側邊欄提示，就點 **允許存取**（再在 Chrome 彈出視窗裡選 **允許**）。也確認一下這確實是 Discourse 論壇（很多論壇頁面底部寫著 "Powered by Discourse"）。如果你在 **這是 Discourse 論壇嗎？** 卡片上給一個其實不是 Discourse 的網站授權了，可以在 **設定 → 論壇存取** 裡移除。

### 摘要裡寫著「已達頁數上限」或「前 1,999 則，共 2,430」。
你給 **每個話題閱讀的頁數** 設了上限，所以更長的話題只根據前幾頁摘要。想包含更多，在設定裡選 **閱讀每一頁**（或者提高上限），然後點 **檢查新回覆**。會花更長時間，也會多花一點錢。預設沒有上限。極少數論壇不報告話題長度，這時為了安全，讀到 100 頁（10,000 篇）就會停。

### 怎麼隱藏論壇頁面上的 Forumind 按鈕？
開啟設定，滾動到 **論壇存取**，關掉 **在論壇頁面上顯示 Forumind 按鈕**，然後點 **儲存設定**。已開啟的論壇分頁上的按鈕會馬上消失，工具列圖示仍然可以開啟側邊欄。

### Ollama 報錯「Ollama 拒絕了連線（403）」。
Forumind 會去掉它自己發往 `localhost`、`127.0.0.1` 和你允許的本機服務位址的請求裡的 `Origin` 請求標頭，這樣預設安裝的 Ollama 就能接受。網頁發的請求不受影響。如果仍然看到 403，請更新 Ollama 並重新載入擴充功能；實在不行，可以用 `OLLAMA_ORIGINS=chrome-extension://*` 啟動 Ollama。

### 會傳送哪些資料，發給誰？
只有完成你的請求所需的論壇內容和你的問題，發給你設定的 AI 供應商（或你的本機模型服務）。什麼都不會發給我們。論壇會收到讀取貼文和搜尋的請求，這些請求從你的瀏覽器發出，帶著你的登入狀態，和你平時瀏覽時瀏覽器發的請求一樣，所以論壇管理員可能在紀錄檔裡看到它們。詳見[隱私說明](guide.md#隱私說明)和[隱私權政策](../../PRIVACY.md)（英文）。

### 為什麼 Chrome 線上應用程式商店的版本比 GitHub 上的舊？
每個新版本都要先經過商店審核（Google 的，Edge 附加元件則是微軟的），耗時從幾小時到幾天不等，所以商店可能比 GitHub 慢一些。審核透過後瀏覽器會自動更新。想馬上用新版，可以從 [Releases 頁面](https://github.com/kccarlos/DiscourseCopilot/releases/latest) 安裝 zip（見[使用指南](guide.md#從-github-安裝最新版)），以後再換回商店版也可以。

### 收費嗎？
擴充功能本身免費。你的 AI 供應商可能按用量收費，通常每次摘要只要很少的錢。本機模型（Ollama、LM Studio）完全免費。

### 不小心刪錯了東西。
8 秒內點側邊欄底部提示裡的 **復原**（或者在不輸入文字時按 Ctrl+Z，Mac 上是 ⌘Z）。超過 8 秒或者關掉側邊欄後，刪除就無法恢復了。

### 怎麼保留某個回答或對話？
點它上面的 **保留**。保留的內容永遠不會過期。你也可以在設定裡延長曆史紀錄的保留時間。

### API 金鑰好像有問題。
開啟設定，檢查 金鑰 和模型，點 **測試連線**。也確認一下你的供應商帳戶裡還有餘額。
